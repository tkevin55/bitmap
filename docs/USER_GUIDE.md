# Bitmap Pixelator - User Guide

## What is Bitmap Pixelator?

Bitmap Pixelator is a web application that transforms your images into pixelated, bitmap-style vector graphics. Perfect for creating retro art, pixel art effects, or scalable graphics from photographs.

## Getting Started

### 1. Creating an Account

1. Visit the website and click **Sign Up**
2. Enter your email, password, and name
3. Click **Create Account**
4. You'll receive 5 free credits to start!

### 2. Uploading an Image

1. Go to the **Editor** page
2. Click the upload area or drag and drop your image
3. Supported formats: PNG, JPG, WebP
4. Maximum file size: 10MB (Free), 50MB (PRO)

### 3. Adjusting Settings

#### Mode Selection

**Black & White (Free)**
- Converts your image to black and white pixels
- Perfect for bold, high-contrast designs
- Great for logos and simple graphics

**Color (PRO only)**
- Preserves colors with adjustable palette
- Advanced dithering for smooth gradients
- Ideal for detailed artwork and photos

#### Pixel Size

- **Range:** 1-50 pixels
- **Smaller values:** More detailed, larger file size
- **Larger values:** More blocky, retro appearance
- **Recommended:** 8-16 for most uses

#### Threshold (Black & White mode)

- **Range:** 0-255
- **Lower values:** More black pixels
- **Higher values:** More white pixels
- **Default:** 128 (balanced)

#### Palette Size (Color mode - PRO)

- **Range:** 2-64 colors
- **Fewer colors:** More stylized, retro look
- **More colors:** More detailed, realistic
- **Recommended:** 16-32 for most images

#### Dithering (Color mode - PRO)

- **None:** Solid color blocks
- **Floyd-Steinberg:** Smooth gradients, natural look
- **Atkinson:** Lighter, more delicate patterns
- **Ordered:** Regular pattern, retro feel

### 4. Exporting Your Image

Click one of the export buttons:

#### SVG (Vector)
- Infinitely scalable without quality loss
- Can be edited in Illustrator, Inkscape, etc.
- Perfect for printing at any size
- Best for: Logos, posters, professional use

#### PNG (Raster)
- High-quality bitmap image
- Transparent background support
- Best for: Web graphics, sharing online

#### JPG (Raster)
- Smaller file size
- No transparency
- Best for: Photos, social media

### 5. Downloading

- Small files download immediately
- Large files get a download link
- Files expire after 1 hour for security

## Tips for Best Results

### Image Selection

- **Good:** High-contrast photos, simple subjects
- **Great:** Logos, portraits, landscapes
- **Avoid:** Very busy images with lots of detail

### Settings Recommendations

#### For Portraits
- Pixel Size: 10-15
- Threshold: 110-140 (B&W)
- Palette Size: 24-32 (Color)
- Dithering: Floyd-Steinberg

#### For Logos
- Pixel Size: 5-8
- Threshold: 128
- Mode: Black & White
- Export: SVG

#### For Landscapes
- Pixel Size: 12-20
- Palette Size: 32-48 (Color PRO)
- Dithering: Atkinson
- Export: PNG or SVG

#### For Retro Art
- Pixel Size: 20-30
- Palette Size: 8-16 (Color PRO)
- Dithering: Ordered
- Export: PNG

### Optimization Tips

1. **Pre-crop your image** to the subject for better results
2. **Start with default settings** and adjust from there
3. **Use preview** to test different settings
4. **Higher pixel sizes** process faster
5. **Color mode** works best with images that already have good color composition

## Frequently Asked Questions

### How many credits do I have?

Check the editor page - your remaining credits are shown at the top.

### When do credits reset?

Free credits reset on the 1st of each month.

### Can I use converted images commercially?

Yes! You own the rights to your converted images. Just ensure you have rights to the original image.

### What's the difference between exports?

- **SVG:** Vector format, infinitely scalable, best for print
- **PNG:** Raster with transparency, best for web
- **JPG:** Smaller files, no transparency, best for photos

### Why can't I use color mode?

Color mode requires a PRO subscription. Upgrade on the Pricing page!

### Can I batch process multiple images?

Batch processing is coming soon for PRO users!

### My conversion failed. What happened?

Common reasons:
- File too large for your tier
- Unsupported file format
- Corrupted image file
- Server timeout (try reducing pixel size)

### How do I cancel my PRO subscription?

1. Go to Pricing page
2. Click "Manage Subscription"
3. Follow Stripe's cancellation flow
4. You'll keep PRO until the end of your billing period

### Can I get a refund?

Contact support@bitmappixelator.com within 14 days of purchase.

### Is my data secure?

Yes! We:
- Use encrypted connections (HTTPS)
- Delete uploaded files after processing
- Never sell your data
- Follow GDPR guidelines
